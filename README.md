# 产品素材工作台

单文件 HTML 产品素材管理工具，零外部依赖、可离线运行。

## 特性

- 四层目录：产品类目 → 工厂 → 产品分类 → 素材分组
- 素材元数据存 IndexedDB，目录骨架存 localStorage，容量不再受限
- 支持连接本地文件夹（File System Access API），素材直接落盘
- 拖拽上传整个文件夹、图片自动压缩、类型自动分区
- 全选 / 批量删除、缩略图懒加载、分组分页（单组超 300 个自动分页）
- 浏览器重启后句柄丢失的友好重连引导

## 使用

直接用浏览器（建议 Chrome 或 Edge）打开 `产品素材工作台.html` 即可，无需安装任何东西。

## 技术要点

- 单文件 HTML，全部 CSS / JS / 图标内联，零 CDN、零框架
- 存储分层：localStorage（目录骨架） + IndexedDB（素材元数据 / 文件内容） + 本地文件夹（真实文件）
- id 索引缓存，素材查找 O(1)；缩略图懒加载 + 分组分页，万级素材不卡顿
- 全选三段式语义，删除同步清理索引，无孤儿数据
